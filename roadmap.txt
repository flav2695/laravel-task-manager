MySQL vs SQLite
Feature	MySQL	SQLite
Database server	Required	Not required
Database storage	MySQL server	Single .sqlite file
phpMyAdmin	Yes	No
Laravel migrations	Yes	Yes
Eloquent ORM	Yes	Yes
CRUD APIs	Yes	Yes
Transactions	Yes	Yes
Concurrency	Better for multiple users	More limited writes
lockForUpdate()	Supported with InnoDB	No equivalent row-level locking
